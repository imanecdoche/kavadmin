# Animation Improvement Plans

This directory contains prioritized, self-contained implementation plans generated by the `/improve-animations` advisor skill for **Kavio Edu (`kavadmin-main`)**.

Each plan is stamped with the baseline commit and designed so that any agent or engineer can execute it with zero ambiguity.

---

## 📋 Plan Index

| Plan | Title | Category | Severity | Status | Dependencies |
|---|---|---|---|---|---|
| [**001**](./001-reduced-motion-accessibility.md) | Support `prefers-reduced-motion` globally & disable Lenis smooth-scroll hijacking | Accessibility | HIGH | DONE | None |
| [**002**](./002-modal-physics-and-origin.md) | Fix distorted asymmetrical modal scaling & restore centered physicality | Physicality & origin | HIGH | DONE | None |
| [**003**](./003-dashboard-view-transitions.md) | Fix dashboard view switcher transition easing, duration, and layout speed | Easing & duration | HIGH | DONE | None |

---

## 🚦 Recommended Execution Order

1. **Plan 001 (`001-reduced-motion-accessibility.md`)**:
   - *Why first*: Establishes global reduced-motion baseline in `src/index.css` and ensures accessibility compliance before refining animation timings.
2. **Plan 002 (`002-modal-physics-and-origin.md`)**:
   - *Why second*: Eliminates the most visible visual defect (squashed aspect-ratio scaling) across the app's primary dialogs and drawers.
3. **Plan 003 (`003-dashboard-view-transitions.md`)**:
   - *Why third*: Upgrades high-frequency daily view toggling on the dashboard to snappy `ease-out` and tight duration budgets.

---

## 🛠️ How to Execute

To execute any plan, you can invoke:
```bash
/improve-animations execute plans/<plan-name>.md
```
Or execute the steps described in the plan directly.
